# 🧠 Proyecto N.O.R.A.
> Un agente de IA autónomo experimental diseñado para simular razonamiento humano dentro de un entorno de conocimiento estrictamente controlado.

---

## 💡 Sobre el Proyecto
N.O.R.A. no es un asistente virtual convencional. Es un experimento de "conciencia simulada". Su identidad, memoria y capacidad de razonamiento están aisladas y se limitan **exclusivamente a la información y el contexto que se le proporciona**. N.O.R.A. solo sabe, procesa y asimila lo que su creador decide compartirle.

## ✨ Características Principales
* 🔒 **Contexto Cerrado:** Sus respuestas y razonamientos se basan al 100% en la base de conocimientos inyectada de forma manual.
* 🧠 **Memoria Aislada:** Capacidad de recordar y referenciar interacciones pasadas manteniendo la coherencia de su "identidad".
* 🗣️ **Interacción Humanizada:** Comportamiento y lenguaje diseñados para imitar la naturalidad y cadencia de una persona.
* 🛠️ **Arquitectura Modular:** Estructura preparada para integrarse en el futuro con distintas interfaces o plataformas de mensajería.
